# 报关单证系统性能优化设计

**日期**: 2026-04-27

## 目标

- 优化整条处理链路的执行时间
- 不改变业务结果
- 不改变 Excel 输出样式、sheet 顺序、字段内容
- 不改变 UI 使用方式

本次优化覆盖：

- 发货单生成
- 备货单生成
- 申报模板填充
- 出运明细登记
- 报关开票登记

## 非目标

- 不调整业务规则
- 不修改公司/品牌映射口径
- 不更换 Excel 生成库
- 不重做 UI 架构
- 不引入会改变输出格式的并行写入

## 优化原则

1. 先量化，再优化
2. 优先减少 I/O，其次减少重复计算
3. 单次改动保持可验证、可回退
4. 每一步都要有回归测试或等价验证

## 当前热点假设

基于代码结构，当前最可能的热点如下：

1. 同一 Excel 文件被重复 `load_workbook/save`
2. 共享盘 `\\192.168.0.45\...` 文件被重复读取
3. 分页设置阶段二次打开工作簿，且可能触发 COM/WPS/Excel 自动化
4. 登记阶段多次扫描目标 Excel 的最后数据行
5. 发货单与备货单流程中存在重复的 DataFrame merge/groupby/清洗

## 方案

### 阶段 1：增加耗时埋点

在不改变现有输出的前提下，为以下步骤增加分阶段耗时日志：

- 读取基础 Excel
- 生成 `result_df`
- 渲染报关资料 workbook
- 填充申报模板
- 登记出运明细
- 登记报关开票
- 设置分页视图

目标是先确认真实热点，避免盲目优化。

### 阶段 2：I/O 优化

- 收敛同一流程内对相同 Excel 的重复打开与保存
- 优先复用已经载入的 workbook / dataframe
- 扩大 `ExcelCache` 的使用范围，减少重复 `pd.read_excel`
- 对共享盘模板与基础资料读取保持现有路径和结果，但减少重复访问次数

### 阶段 3：计算优化

- 复用中间 DataFrame，减少重复 merge/groupby
- 将低效的逐行 `apply` 优先替换为等价向量化写法
- 避免同一流程内重复做相同的 SKU/店铺/品名清洗

### 阶段 4：登记流程优化

- 合并“查重/查最后一行/写入后校验”中可以复用的工作簿读取
- 避免多次独立扫描同一登记 Excel
- 保持登记写入位置、内容、格式完全不变

## 风险控制

- 所有优化必须以“结果不变”为前提
- 每一步优化后都跑现有自动化测试
- 对关键输出路径保持人工抽样验证：
  - 报关资料主文件
  - 发票合同文件
  - 申报模板
  - 出运明细登记
  - 报关开票登记

## 验证方式

- 自动化：运行现有 `unittest` 全量测试
- 人工验证：
  - 同一输入文件优化前后输出文件名一致
  - sheet 数量、顺序、标题一致
  - 关键字段值一致
  - 登记目标文件与写入行数一致
  - 样式不出现明显变化

## 实施顺序

1. 增加耗时埋点
2. 优化分页设置与模板/登记 I/O
3. 优化 DataFrame 重复计算
4. 跑全量测试并做人工抽样校验
